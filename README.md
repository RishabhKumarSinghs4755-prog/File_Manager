📁 File Manager App
A simple File Manager application built with Python and Streamlit that demonstrates CRUD (Create, Read, Update, Delete) operations, file handling, 
and exception handling through an interactive web interface.
🚀 Features
* 📄 Create files
* 👀 Read/view file contents
* ✏️ Update/edit files
* 🗑️ Delete files
* ⚠️ Exception handling for common file-operation errors
* 📂 Simple and interactive file-management interface
* 🖥️ Built with Streamlit

🛠️ Technologies & Concepts Used
Python
Streamlit
File Handling
CRUD Operations
Exception Handling (try, except)
